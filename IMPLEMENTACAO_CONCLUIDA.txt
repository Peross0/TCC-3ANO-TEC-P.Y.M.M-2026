📋 RESUMO EXECUTIVO

A funcionalidade de alternância (toggle) do botão "Tenho Interesse" foi 
implementada com sucesso no aplicativo mobile do Conecta Fácil. 

O usuário agora pode:
✅ Marcar interesse em uma vaga
✅ Desmarcar interesse clicando novamente
✅ Repetir quantas vezes quiser
✅ Visualizar estado persistente após fechar/abrir o app
✅ Manter estado independente para cada vaga

═══════════════════════════════════════════════════════════════════════════════

🎯 FUNCIONALIDADES IMPLEMENTADAS

1. MARCAR INTERESSE
   - Usuário clica "Tenho interesse"
   - Sistema envia POST /candidates/vacancies/{id}/apply
   - Botão muda para "Interesse registrado" com fundo preenchido
   - Vaga é registrada no banco de dados

2. DESMARCAR INTERESSE
   - Usuário clica "Interesse registrado"
   - Sistema envia DELETE /candidates/applications/{id}
   - Botão volta para "Tenho interesse" transparente
   - Vaga é removida do banco de dados

3. ISOLAMENTO DE VAGAS
   - Cada vaga mantém seu próprio estado
   - Marcar em uma vaga não afeta as demais

4. PERSISTÊNCIA DE DADOS
   - Dados salvos no banco de dados (tabela interests)
   - SessionContext carrega dados ao iniciar
   - Estado persiste após fechar e abrir o app

5. TRATAMENTO DE ERROS
   - Mensagens de erro claras
   - Botão volta ao estado anterior em caso de erro
   - Usuário pode tentar novamente

🔧 DETALHES TÉCNICOS

LÓGICA IMPLEMENTADA:

Função applyToJob() em home.js:
  1. Verifica se usuário já aplicou: isCurrentlyApplied = appliedVacancyIdSet.has(id)
  2. Se sim: Envia DELETE /candidates/applications/{id}
  3. Se não: Envia POST /candidates/vacancies/{id}/apply
  4. Atualiza estado local: setAppliedVacancyIds()
  5. Atualiza SessionContext: setSessionData()
  6. Exibe mensagem de sucesso/erro

Componente JobCard:
  - Recebe props: isApplied, isApplying, onApply
  - Renderiza botão com texto dinâmico
  - Aplica estilos condicionais baseado em isApplied
  - Desabilita apenas enquanto processa (isApplying)
